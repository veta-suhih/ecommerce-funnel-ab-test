# Анализ воронки продаж и A/B-тестирование в E-commerce

Проект посвящен продуктовой аналитике на основе данных крупного маркетплейса (Ozon). 
Включает построение воронки продаж, поиск узких мест и дизайн A/B-теста для проверки новой фичи.

**Стек:** Python (Pandas, SciPy, Statsmodels), SQL (PostgreSQL), Jupyter Notebook.
